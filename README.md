# Student Management System

A Python-based desktop application designed to manage student records through a simple and user-friendly graphical interface.

## Overview

The Student Management System provides an interactive dashboard for managing student information. It uses Tkinter for the graphical user interface and SQLite for storing student records.

## Features

- Add new student records
- Update existing student information
- Delete student records
- Search students by ID, name, or course
- Display all student records
- Sort students by ID, name, age, or course
- Display the total number of students
- Export student records to Excel
- Keyboard navigation for data entry

## Technologies Used

- Python
- Tkinter
- SQLite
- Pandas
- Excel

## Database

The application uses SQLite to store student records with the following fields:

- Student ID
- Name
- Age
- Course
